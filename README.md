# Modpack Instance Repository

Welcome to the Modpack Instance Repository! This repository is designed to help you easily update your modpack to ensure compatibility with our server. By using this repo, you can quickly get the latest version of the modpack and join the server without any hassle.

## How It Works

This repository contains all the necessary files and configurations for the modpack. By cloning or downloading this repository, you will have access to the latest mods and updates required to connect to our server.

1. **Install the Requirements:**
   First use an instance launcher (for example SKlauncher (recommended), Modrinth, CurseForge, etc) to create an instance inside a separate folder than .minecraft folder with **Minecraft version 1.21.1** and **NeoForge version 21.1.203**, 

   then you can either grab this tool to update it into proper version: https://github.com/minecraftwithtwink/Modpack-Updater/releases/latest

   or if you wanna take care of things manually and already have git then clone all the files from this repo into it and replace / overwrite them.
   open the instance folder inside a terminal

2. **Update Your Modpack:**
   To keep your modpack up to date, you can use the [Modpack-Updater](https://github.com/minecraftwithtwink/Modpack-Updater/releases/latest) tool, or simply pull the latest changes from the repository by running this command inside instance folder in a terminal:

   ```bash
   git pull origin main-beta
